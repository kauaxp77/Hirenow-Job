## 💻 Sobre o Projeto

O **Hirenow** é um projeto de recrutamento para facilitar o elo entre candidatos buscando ótimas oportunidades com empresas/recrutadores de talentos. A aplicação foca numa usabilidade simples para ambas as partes.

Através dessa plataforma full-stack eu aprimorei competências na gestão de banco de dados, tratamentos de interações com o sistema (envios de candidaturas) e manipulação com PHP tradicional e MySQL para prover o backbone.

## 🚀 Funcionalidades Chaves

- **Módulo de Empresa / Recrutador:**
  - Registro de oportunidades e ofertas de emprego na íntegra.
  - Painel para detalhar as funções, salário, requisitos, tags e controle interno da vaga.
  - Sistema de conversas/chat para entrar em contato com os candidatos que passaram em triagens preliminares.

- **Vagas e Job Board**
  - Módulo que distribui as vagas atuais em páginas interativas filtráveis e pesquisáveis com detalhes para os convidados.

- **Módulo de Candidatos & Chat:**
  - Iniciar candidaturas ao enviar detalhes solicitados na vaga (Comunicação indireta e de algoritmos base entre as duas tabelas no MySQL).
  - Possibilidade de utilizar uma sala de bate-papo construída sob a plataforma que simplifica as conversas de primeira fase e entrevistas técnicas ou feedbacks, permitindo responder a recrutadores sem sair da aplicação.

## 🛠️ Tecnologias Utilizadas

- **Front-end UI:** Desenhado em HTML5 / CSS para apresentar a estética e visual aos navegantes e corporativos.
- **Back-end:** Desenvolvimento tradicional e limpo em PHP.
- **Banco de Dados e Querying:** Interações relativas feitas via MySQL (utilizando scripts gerados com MySQL Workbench).
- **Rodando Servidor Localmente:** Prático utilizando XAMPP/WAMP ou Built-in Server.

## ⚙️ Testar o Sistema
1. Instale e garanta que o Apache + MySQL estão ativados (via XAMPP, etc).
2. Clone o repositório na pasta `htdocs` ou em sua WWW ROOT.
3. Importe o banco de dados SQL que compõe as tabelas do projeto (e dados bases caso tenha DUMP).
4. Utilize as portas padrões locais.
